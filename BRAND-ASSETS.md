# Registro de activos oficiales Speed Pack

Este proyecto utiliza los recursos de marca como material fuente, sin redibujar, recolorear, inclinar, deformar ni aplicar filtros. Las formas nuevas de interfaz se construyen exclusivamente con la paleta y las tipografías documentadas.

## Tipografías

Se conservaron los contornos de las fuentes incrustadas en los PDF y solo se convirtió el contenedor para uso web (`WOFF`): Associate Mono Regular/Medium/Bold, Dothed Regular y FK Raster Grotesk.

## Paleta cerrada

`#DEFF1F`, `#4C2796`, `#331A63`, `#180935`, `#A29CFF`, `#E5FAAE`, `#212020`, `#F5F5F0`.

No se debe introducir otro color hexadecimal en la interfaz ni usar filtros CSS sobre el logo, el ícono o Speedy.
